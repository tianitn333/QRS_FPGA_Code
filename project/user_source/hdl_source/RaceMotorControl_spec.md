# RaceMotorControl

接口约定：两轴共用500kbit/s CAN，ID1第一名/ID2第二名；同打印件共用原始标定；人工放初始位置后显式清零；下一局先自动归位；速度50RPM。只显示第一/第二名，不新增第三轴，不考虑并列机械展示。本版本同源帧按L1/L2/L3顺序产生唯一1/2/3，屏幕和电机一致。

75MHz单域，低有效复位。SW2授权，之后SW3新上升沿确认人工初始参考；关闭SW2停止/失能两轴并作废参考。关着SW2允许原图像工程独立比赛，不触发机械。上电即便SW3保持打开也须有授权之后新边沿才确认。参考流程对轴1再轴2执行闭环、清零、使能、置参考标志、状态及位置读取；不自动寻零。命令层输入ready/ done/ok有明确握手，不因电机ACK直接认定到位。

位置命令绝对脉冲0/-1727/-2817/-4047；预期编码器幅值0/35369/57692/82883，容差128计数约0.703度，零点可正负微差。非零目标须负方向，32位高位不得被截断。状态要求enabled、无stall/protection且参考标志Oac_TF=1，且arrived后仍读36检查位置；未到位20ms继续轮询，整个双轴操作10s时限。axis1完成后axis2，避免并发主机调度开销。

最终包须全部三道完成、无检测故障、唯一1/2/3排列；按完整raceID去重，每个ID最多消费一次，回放不连接该接口。开始下一局的请求合并为一个pending，展示结束后收回两旗，读状态及编码器确认后才输出race_go。故障停止/失能并锁存；关SW2后再人工参考，不能自动重发失败动作。

关闭SW2的软件停止须等待正在进行的有界CAN事务收尾，最坏包括500ms应答时限，不是独立硬件急停。总线不通时不能保证停止命令送达；不声称机械停稳。断电不能保存参考，用户必须重新放初始位置。

验证覆盖两轴初始化顺序、六排名排列、重复raceID、图像单用、归位后GO、错误状态/坐标/超时、停止/失能、失效参考与复位不自动启动。WaveJSON：`{"signal":[{"name":"clk","wave":"p............"},{"name":"arm","wave":"01..........."},{"name":"reference","wave":"0.10........."},{"name":"state","wave":"2.2..2..2..2.","data":["REF","INIT","READY","MOVE","READY"]},{"name":"final_valid","wave":"0......10...."},{"name":"request","wave":"0..1010.1010."}]}`。执行延迟取决于总线和到位，示意不作固定周期承诺。

停止流程中的撤销授权不会屏蔽后续STOP/DISABLE命令。新增故障停止期间关SW2专门用例，验证两地址仍各收到一次STOP和DISABLE。

## Oac_TF协议纠正（2026-11-04）
命令接口扩为4位；新增命令8，发送50 01 6B，匹配50 02 6B。手册73/77页：Oac_TF默认0，可软件置1，驱动掉电重启回0；1表示本次参考标记仍在，不能解释成掉电异常。人工参考时在使能后置1再读取状态/坐标；每轴MOVE之前先读3A，要求标记1、enabled且无堵转/保护。读36确认位置后再读3A，标记及状态仍有效才完成，归位不误放行。标志丢失报ERR4并作废参考；软件轮询不等于硬件急停。
