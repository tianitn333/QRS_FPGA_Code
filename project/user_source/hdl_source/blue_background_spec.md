# blue_background 模块规格（2026-10-18）

## 接口与模式

RGB888、valid/user/last输入，75MHz单像素/拍，无反压；低有效异步控制复位。输出RGB、valid/user/last及allow经过原有三寄存级，ready/busy为校准状态。IMG_W、IMG_H为8的倍数，工程1280×720。外部保持完整光栅与消隐；至少五拍帧间空隙用于排空学习写回，工程消隐远大于此值。

NOISE_CAL_ENABLE默认0兼容旧8帧模式；工程显式1。NOISE_MARGIN默认8，支持0..256；MIN_DELTA默认16、MIN_SUM默认48、CHROMA_SHIFT默认4。

## 校准和存储

IDLE→SETTLE（默认37500000拍）→ARM（下一完整帧）→CAPTURE（8帧均值）→NOISE（启用时8帧偏差）→COMMIT→READY（下一帧首）。校准中allow无效；重新校准和复位清除有效状态，内存不清零，首个采样阶段重建有效内容。

每8×8区域，前8帧512个像素求和，3×17位累加，取高8位为均值；后8帧记录每个通道所有像素相对冻结均值的最大绝对差，包含区域纹理差异与时间波动。NOISE第1帧逐区域转换51位格式；后续存mean24+deviation9×3，最后一次提交转换为mean24+tolerance9×3。T=max(16,deviation+8)，255+8=263不得溢出。

学习支路独立流水：ERAM/RGB对齐→绝对差及旧模型寄存→行/区域/跨帧最大值寄存→余量和限幅写回。均值原路径、RGB/allow路径和首帧检测响应不增加延迟。partial_memory复用42位区域行累加RAM；background_memory仍51位，ERAM容量不新增。

## 前景条件

至少一通道abs(pixel-mean)>=该通道T；三通道差之和>=48；R/B或G/B相对背景变化>=1/16，以20位交叉乘法比较，无除法。背景B<16绕过色度检查。ready后模型冻结，静止目标不会自动吸收。该门控只作用于蓝色统计，红绿继续检测。

## 证据与边界

155帧独立参考模型检查完整RGB/标志/allow与冻结模型内容；含纹理、噪声、精确阈值等号、sum47/48、纯亮度缩放、暗背景、263容差、重新校准、均值/偏差阶段复位。真实720p检测独立验证四边四相位首帧框及中心。实际固定机位的空场/目标配对、600帧及10分钟观察仍须实板验收。
