# anlogic_logo_palette：只读压缩Logo及一拍预取

本版本只优化Logo/OSD。颜色识别、色度/灰度降噪、FILL语义与容量、运动及七槽DDR回放均保持原源码。

| 端口 | 方向/位宽 | 契约 |
| --- | --- | --- |
| clk | input 1 | 75MHz HDMI像素域；无新时钟域 |
| rst_n | input 1 | 低有效异步断言，沿用HDMI域释放；清除读取有效标记、地址与银行选择 |
| I_addr | input 15 | 原官方Logo线性地址，调用者提前一个既有流水阶段给出 |
| O_pixel | output reg 25 | bit24为有效覆盖位，低24bit为原RGB888；模块读延迟一拍 |

初始化文件使用固定相对目录`logo_palette_data/`。TD相对RTL源文件目录解析；ModelSim原厂模型相对仿真工作目录解析，测试按哈希复制同一组数据。八份dath各1024个18bit字，不在运行期写入。禁止缺文件时用空内容替代；全机源哈希须覆盖八份文件。

原始6387像素全部保留：常用两色3788像素作组合地址译码，其余2599个像素存入4096×36位只读稀疏表，包含valid、9bit桶标签和24bit精确RGB。表地址为高6bit地址与512项位移表的异或。valid及桶标签匹配才覆盖常用色；给定桶标签和表地址可唯一还原原地址，避免未命中的透明或常用色像素被误覆盖。全32768地址模型与原表逐字相同，不作量化或降色。

使用六块18×1024 ERAM；第四逻辑银行的两个18bit面为常量零，端口A/B写使能均恒零。B口在clk上升沿读取，银行选择和原地址同拍锁存；没有CDC、反压或动态配置。rst_n断言时O_pixel被read_valid屏蔽为0；释放后首次有效读取恢复。X/Z地址保持原case默认零的外部行为。

hdmi_mixer从S_x_1d/S_y_1d/S_video_de_1d产生下一阶段的Logo地址，原先组合查表使用S_x_2d/S_y_2d。因此模块内部一拍读取被前移的地址抵消，现有S_p3/末级输出、DE/坐标、Logo透明优先级及文字相位均不增加延迟。矩形外地址固定0，保持原透明行为。

原生验证：32768个完整25bit字、242组X/Z、读前保持/读沿更新、异步复位与恢复；四种模式四个完整720p光栅，4950180次阶段检查，全部25548个原始可见Logo像素、透明/边界/优先级一致。另运行既有FILL按键及真实光栅回归。原厂PH1P_LOGIC_ERAM与全局PH1P_PHY_GSR参与仿真，不用自写初始化模型证明新存储。

时序情景WaveJSON另存`anlogic_logo_palette_prefetch.json5`；没有伪造渲染SVG。static compile/AST/风格与ModelSim/综合/布线/独立STA分开记录，局部综合不代表整机净收益或实板通过。
