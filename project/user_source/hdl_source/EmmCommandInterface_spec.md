# EmmCommandInterface

75MHz，低有效同步释放复位。ready时request脉冲接收axis/command/target，axis0/1对应地址1/2。命令0闭环、1清零、2使能、3绝对位置、4状态、5累计编码器位置、6停止、7失能、8置参考标志。target为有符号16位命令脉冲，速率固定50RPM/加速度100，绝对模式/不等待广播。

完整经典扩展数据帧：ID=地址<<8|片号；FD首片8字节、末片5字节且重复FD；默认间隔5ms。payload从高字节开始。request不自动重发；500ms事务时限包含排队、发送和应答。TX ready/valid后报文不可更改；DONE只在实际CAN发送完成后等待应用层响应。电机应用响应可能比轮询TX完成更早，在ST_SENT/ST_ACK捕获。

只接受正确地址片0、对应功能字、长度和6B校验；正常ACK02，E2/EE失败，FD9F到位提示不是FD接收ACK。STATUS返回3A状态，POSITION返回36+方向+32位幅值，保留多圈。done是一拍，ok区分成功/失败，error1超时/2拒绝/3传输故障。命令ACK不等于到位，上层必须检查3A和36。

清零只是一条有显式请求的协议操作，本模块不自动清零、寻零或移动。上层必须完成授权和机械参考确认。复位丢弃未完成事务，不自动重发。复位时同时复位报文层，避免遗留传输。物理断电无法由无回包瞬时确定。

验证覆盖：两地址8种命令、三目标负脉冲、首末片字节、早到ACK、错地址/功能/长度、拒绝/无应答、正负32位位置和状态原样返回、复位。

WaveJSON：`{"signal":[{"name":"clk","wave":"p..........."},{"name":"request","wave":"010........."},{"name":"tx_valid","wave":"0.1.0...1.0."},{"name":"tx_done","wave":"0....10....1"},{"name":"rx_valid","wave":"0.........10"},{"name":"done","wave":"0..........1"}]}`。片间等待及总线时延可变。

## Oac_TF协议纠正（2026-11-04）
命令接口扩为4位；新增命令8，发送50 01 6B，匹配50 02 6B。手册73/77页：Oac_TF默认0，可软件置1，驱动掉电重启回0；1表示本次参考标记仍在，不能解释成掉电异常。人工参考时在使能后置1再读取状态/坐标；每轴MOVE之前先读3A，要求标记1、enabled且无堵转/保护。读36确认位置后再读3A，标记及状态仍有效才完成，归位不误放行。标志丢失报ERR4并作废参考；软件轮询不等于硬件急停。
