# 隐藏黄字版上板操作

最新版bit和SHA256见包根`RELEASE.json`及`program/`。本版只隐藏黄色C0～C3，内部探针保留，绿色CAN/ERR正常显示。接线、电机设置及图像/颜色/FILL按键沿用[原整机指南](FULL_KEY_GUIDE_REFERENCE.md)。

1. SW2、SW3关闭，下载新bit。等待驱动上电完成，把两旗帜放在可重复的机械初始位置。
2. 进入MOTION界面。打开SW2，等约1秒，再把SW3从关拨到开，建立两轴参考。KEY1仍为原图像/编辑功能。
3. 正常初始化应为CAN3 ERR0。开始比赛后，三道结果完整时自动驱动两旗帜展示。
4. 下一局短K2：若处于IDLE/DONE/ERROR，先发双轴绝对零位命令，编码器及到位状态确认后才放行新比赛。等机构完成动作。
5. 若短K2时仍处于PREPARE/READY/RUNNING，这次按键先结束图像检测；再短按一次K2才进入下一局归位。回放中的短K2先退出回放。
6. SW2关闭会停止/失能并使参考失效，不是归位键。重新建立参考时按步骤1～2进行；SW3确认的是人工机械初始位置，伸出时不能用它替代收旗。

本工程的“归零”是返回SW3确认的参考坐标0，最终读回允许±128编码器计数；不是带限位开关的自动找原点。没有新增独立“只收旗”按键。

颜色参数只在本次上电期间保留；系统复位、重新下载或掉电恢复默认。红色默认24/1.5/1.5，其余默认不变。

若需要重新看到C0～C3，使用保留的`motion_can_probe_20261104_a820495a.bit`及[字段说明](PROBE_FIELDS_REFERENCE.md)。本包不含自动烧录流程；隐藏版的实际上板结果需另行记录。
