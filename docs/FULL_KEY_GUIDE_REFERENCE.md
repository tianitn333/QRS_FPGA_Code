# PH1P35完整主工程20ms版上板操作

本指南描述命令间隔 20ms 版的整机操作。当前发布的 bit 与 SHA256 以包根 `RELEASE.json` 及 `program/` 为准。

普通命令完成后至少20ms，STOP/DISABLE绕过；不发送0x7E0/0x7E1诊断帧。KEY1仍是图像功能键。完整FILL、颜色易失编辑、排名和七槽回放保留。

## 1. 先认清按键和开关

| 板上标识 | FPGA球位 | 用途 |
| --- | --- | --- |
| K1 / KEY1 | D5 | 切图像模式；按当前界面进入编辑、选字段或显示/隐藏面板 |
| K2 / KEY2 | A9 | 比赛准备/结束、回放；EDGE子模式切换；COLOR选参/退出编辑 |
| K3 / KEY3 | B9 | 数值减小；回放上一车道 |
| K4 / KEY4 | C7 | 数值增大；回放下一车道；COLOR恢复默认确认 |
| SW1 | A4 | COLOR编辑时：0/下为RGB彩色预览，1/上为HIT黑白命中预览 |
| SW2 | B4 | CAN电机授权开关：0关闭授权，1允许建立参考并控制双轴 |
| SW3 | E11 | 人工机械初始位确认：SW2授权后，必须从0拨到1产生一次新上升沿 |

以板卡丝印和屏幕状态确认开关；SW2/SW3的“关/开”分别指逻辑0/1。

- **短按**：按住约0.1～0.3秒后松开。K1/K2在松开时触发。
- **长按K1/K2**：保持约1秒，门限约0.8秒；松开不会再触发一次短按。
- **K3/K4连调**：按下即调一步；持续约0.4秒后，每约0.08秒再调一步。
- **恢复颜色默认值**：仅在指定DEFAULT项，单独长按K4约1.5秒。
- 参数和画面按帧边界更新，操作后稍等画面变化，不要连续猛按。

**K3/K4不是电机点动键。本版没有按键手动点动、单轴直选或在线改电机速度功能，双轴速度固定50RPM。**

## 2. 第一次上板：先验证图像，再启用CAN

1. 将**SW2、SW3都拨到0/关闭**，由用户下载本指南对应的bit。
2. 等待摄像头和显示启动。上电默认进入 **MOTION EXP**；此时CAN未授权，屏幕右上应为 **CAN0**。
3. 短按K1进入 **ORIG** 原图，检查图像、方向和红绿蓝显示。再按K1依次检查GRAY、EDGE、COLOR；FILL和颜色编辑的操作见后文。
4. 新版**不读写SD卡**，可不插卡；不需要等待SD加载，也不需要等待SAVED。
5. 退出所有参数编辑，短按K1循环到 **ORIG**，长按K2约1秒，返回 **MOTION EXP**。
6. 图像正常、CAN接线及机械行程核对完毕后，再按第3节建立电机参考。

CAN0只表示FPGA没有授权，**不能据此判断外部驱动已经失能**。初次验证时由用户按驱动自身方式确认机构静止。

如果只验证视觉比赛，可以一直保持SW2=0：在MOTION短按K2，等绿色READY后放车；本次只验证检测和回放，不进行旗帜展示。

### CAN接线和驱动设置速查

| FPGA排针 | 连接收发器 | 备注 |
| --- | --- | --- |
| J2-27 / P9 | TXD | FPGA发送，接收发器逻辑输入 |
| J2-28 / P8 | RXD | FPGA接收，接收发器逻辑输出 |
| J2-29 | 3.3V | 使用兼容3.3V逻辑的收发器 |
| J2-30 | GND | 与驱动信号地共地 |

按原理图J2编号及1脚标记找排针；旧PDF的J1/J2表头曾对调。GPIO不直接接CANH/CANL。收发器CANH/CANL连接两台电机同一总线，两个物理末端各120Ω，电机使用独立额定电源；STB/EN按收发器正常工作模式连接。

驱动采用 **Emm、CAN1_MAP、500kbit/s、ID1/ID2、16细分、S_Vel_IS关闭、Response=Receive或Both、校验6B**。FPGA命令速度50RPM、加速度100。不要在FPGA控制期间让USB-CAN工具同时循环发送控制或清零命令。

## 3. 建立两台电机的人工初始位

每次重新上电、系统复位、重新下载，或撤销授权/故障恢复后，都重新执行本节。

1. 保持SW2=0、SW3=0，等待两台驱动初始化完成。
2. 用户将**两面旗帜放回同一可重复的机械初始位置**。需要手动移动时，先用驱动自身方式失能。确认方向和可用行程，L3目标超过一圈。
3. 将 **SW2拨到1**。等待右上显示 **CAN1** 并稳定；首次操作可等约1秒，让CAN初始化完成。
4. 确认机构确实处于机械初始位置后，将 **SW3从0拨到1**。
5. 等待 **CAN2 → CAN3，ERR0**。控制器会依次初始化两轴、清零、使能并读取反馈；CAN3/ERR0表示双轴参考建立完成。
6. SW3成功确认后可以保持为1，正常下一局不用反复拨SW3。

**此时坐标0是“旗帜收回的机械初始位”，不是L1。旗帜已经伸出时，不要直接用SW3把伸出位置确认为新零点。**

如果SW3原先已经为1，本次不会产生有效确认；先拨回0，再拨到1。如果一直停在CAN1且没有动作，待CAN初始化后重新产生SW3的0→1变化。若出现CAN6/ERR非0，按第10节恢复。

## 4. 正常比赛：照这个顺序操作

### 第一局

1. 确认右上 **CAN3 / ERR0**。
2. 保持相机固定，清空三道，确认画面为 **MOTION EXP**。
3. **短按一次K2**。屏幕可能先显示 **CAN5**，双轴归0并读回确认后才进入摄像头比赛准备。
4. 等待运动状态从 **PREPARE** 变为绿色 **READY**。CAN3只表示电机就绪；**要看运动区域的绿色READY，才能放车**。
5. READY后直接放车，三道均从屏幕右方向左冲线。**不用再按K2开始**。
6. 画面会进入RUNNING；三道均有效到达后显示DONE及各道名次。
7. 三道成绩完整后，自动显示 **CAN4**：ID1旗帜显示第一名，ID2旗帜显示第二名，完成反馈核对后返回 **CAN3 / ERR0**。

显示顺序：**上L3、中L2、下L1**；屏幕底部成绩卡从左到右为一道、二道、三道。只有两台电机，没有第三名电机。同一源帧触线按L1→L2→L3固定优先级排出唯一名次，屏幕与旗帜一致。

### 下一局

1. 先看完或回放上一局；清空赛道，保持机位不变。
2. 在非回放的MOTION界面，**再短按一次K2**。
3. 等待CAN5收旗、两轴归0并确认，随后等待新一局运动绿色READY，再放车。

**开始下一局会清除上一局的证据。** 需要回看时，先完成第5节，再开始下一局。归位或展示期间不要连按K2；控制器最多合并保留一个下一局请求。

### 中途结束本局

在PREPARE、READY或RUNNING状态，短按K2会提前结束当前检测。因此READY后不要习惯性再按一次K2。提前结束可能只有部分成绩，不能据此期待完整双旗帜展示。

中止图像检测不等于电机急停。撤销电机授权使用SW2，实际紧急停止使用驱动/供电系统的硬件措施。

## 5. 查看证据回放

| 当前状态 | 操作 | 结果 |
| --- | --- | --- |
| MOTION结果DONE或运动ERROR | 长按K2约1秒 | 进入本局证据回放；无证据时给出空提示 |
| 回放中 | K3 | 上一车道，循环切换 |
| 回放中 | K4 | 下一车道，循环切换 |
| 回放中 | 短按K2 | 退出回放，保留本局结果；这一按不会开始新局 |

回放只查看已保存证据，不重新触发电机。不是每个错误局都有有效证据，也不是每一道都必然保存成功；以页面提示为准。

**退出回放后，再短按一次K2，才是下一局。** 回放中K3/K4翻页；非回放的MOTION空闲/结果/错误状态下，K3/K4会调整运动参数，操作前先确认界面。

## 6. 调整三道ROI和终点线

仅在MOTION的 **IDLE、DONE或ERROR**、且未进入回放时调整；PREPARE/READY/RUNNING不开放调整。

- 长按K1约1秒：循环选择 **X → Y → LINE → THR → X**，看屏幕 `EDIT` 后的字段。
- K3减、K4加；按住可连调。上电默认已经选中X，**不必先长按K1才能调整**。
- 改完后清空赛道，再短按K2准备新局，等待READY。

| 字段 | 默认值 | K3/K4每步 | 范围 | 作用 |
| --- | ---: | ---: | ---: | --- |
| X | 160 | 4像素 | 16～752 | 三道ROI的共同水平位置 |
| Y | 512 | 2像素 | 472～528 | 下方L1的ROI起始Y，L2/L3随固定道距一起移动 |
| LINE | 40 | 1像素 | 8～55 | 终点线的相对位置 |
| THR | 24 | 1 | 8～64 | 运动前景判定阈值，与COLOR的红色DIFF是两个独立参数 |

三道ROI均为512×96像素，道距208像素，采样8×8。默认L1/L2/L3起始Y分别为512/304/96；默认终点屏幕X=160+128+40=328。LINE不是屏幕绝对X坐标；调整X也会移动终点线。

以上为固化默认值和步长，按屏幕选中字段及ROI/线位置观察调整结果。运动参数不保存到SD，系统复位/重新下载/掉电后恢复默认。

## 7. 图像模式与FILL

### 模式切换

- MOTION界面短按K1：进入ORIG。
- 正常图像界面短按K1：**ORIG → GRAY → EDGE → COLOR → ORIG**。
- 退出所有参数编辑后，在ORIG界面长按K2约1秒：返回MOTION EXP。
- 在EDGE下短按K2：**DETECT → EXTRACT → FILL → DETECT**，以屏幕标签为准。

上电从MOTION进入FILL的一条常用路径：**K1短按 → ORIG；K1短按 → GRAY；K1短按 → EDGE；K2短按两次 → FILL**。

### FILL参数编辑

| 操作 | 作用 |
| --- | --- |
| 在FILL长按K1 | 进入FILL参数编辑 |
| 编辑中短按K1 | 下一项：RF→CG→BT→GC→MW→RF |
| 编辑中K3/K4 | 当前值减/加 |
| 编辑中再次长按K1 | 退出FILL编辑 |

FILL编辑要用**长K1退出**，不要用COLOR的长K2退出方式。

| FILL字段 | 默认值 | 含义 |
| --- | ---: | --- |
| RF | 8 | 最短背景RUN过滤阈值 |
| CG | 0 | 内部缺口连接容忍 |
| BT | 0 | 与图像边界接触/连接容忍 |
| GC | 0 | 允许的缺口桥接计数 |
| MW | 24 | 最小上色RUN宽度，增大可减少碎小填充 |

容量为6144 RUN，约80%时显示琥珀色；溢出显示红色并丢弃该次结果、回退实时边缘。开口区域不会强制填满；保留的两行OR捕获会产生2像素纵向台阶，FILL画面也可能比实时画面稍旧。

FILL参数只在当前运行期间保留；复位/重新下载/掉电恢复默认。COLOR的GLOBAL→DEFAULT不会重置FILL参数或运动ROI。

## 8. COLOR颜色阈值编辑

在正常COLOR界面，长按K1约1秒进入编辑。

| 编辑中的操作 | 作用 |
| --- | --- |
| 短按K1 | 上一项，页首可退到上一页末项 |
| 短按K2 | 下一项，页末可进入下一页首项 |
| K3 / K4 | 当前数值减 / 加；按住可连调 |
| 长按K1 | 隐藏/显示面板，仍处于编辑状态 |
| 长按K2 | **退出COLOR编辑** |
| SW1=0/下 | RGB彩色预览 |
| SW1=1/上 | HIT黑白命中预览 |

**COLOR中长K1只是隐藏面板，不是退出编辑。** 要切模式或返回比赛，先长K2退出。隐藏面板时仍可调值，操作前确认自己是否仍在编辑。

### 页面顺序与上电默认值

| 页面 | K2向后选择的顺序 | 默认值 |
| --- | --- | --- |
| RED | DIFF → R/G → R/B | **24 / 1.500 / 1.500** |
| GREEN | DIFF → G/R → G/B | 12 / 1.125 / 1.500 |
| DEEP BLUE | DIFF → B/R → B/G | 12 / 1.500 / 1.250 |
| LIGHT BLUE | DIFF → B/R → G/R | 20 / 1.250 / 1.250；浅蓝扩展关闭 |
| GLOBAL | LUMA → SAT → AREA → DEFAULT | 44 / 18 / 32 / 恢复默认操作项 |

15项数值及1项DEFAULT构成循环，K1反向移动。RED的DIFF第一项短按K1，可直接到GLOBAL→DEFAULT。比例每步为1/32，约0.03125，界面显示三位小数；AREA是采样点面积阈值，不是完整物体像素数。

数值到上下限后保持，不会从最大值跳到最小值。K3/K4不要同时按，同按不会产生加减。

HIT白色表示像素命中当前页面的判据；像素命中仍要经过面积等筛选，才能形成检测框。浅蓝扩展在本版保持关闭，LB菜单参数不会把它重新打开。

### 恢复15项颜色默认值

1. 在COLOR编辑中，选中 **GLOBAL → DEFAULT**。
2. **先完全松开K4**，再单独按住K4约1.5秒。
3. 松开后等帧边界生效。全部15项恢复上表默认，红色恢复24/1.5/1.5。

离开DEFAULT、退出编辑或确认时同时按其他键，会取消确认。提前按住K4再进入DEFAULT不算有效确认。

### 新版参数保存规则

- 修改后在寄存器中保留，退出编辑、切模式、开始下一局都不会清除颜色修改值。
- 系统复位、重新下载或掉电后，恢复本版固化默认。
- **没有保存键，也不再自动保存到SD；不用等SAVED。** APPLYING表示仍在等待帧边界生效，IDLE不表示已持久保存。

## 9. 看懂屏幕状态

### 运动状态行

| 显示 | 含义 / 操作 |
| --- | --- |
| IDLE | 运动检测空闲；对齐赛道后短K2准备 |
| PREPARE | 冻结曝光、等待反馈和学习空场；保持赛道空且机位不动 |
| 绿色READY | 本局已准备好，可以直接放车 |
| RUNNING | 正在统计有效到达，避免再按K2 |
| DONE | 本局结束；看各道成绩，或长K2回放 |
| ERROR数字 | 运动检测报错；记录完整数字和画面，排查后清空赛道重开 |

### 右上CAN状态

| 显示 | 含义 |
| --- | --- |
| CAN0 | FPGA未授权；不等于外部驱动已失能 |
| CAN1 | 等待用户确认人工机械初始位 |
| CAN2 | 两轴初始化、清零和检查中 |
| CAN3 / ERR0 | 电机控制就绪；放车仍须等待运动绿色READY |
| CAN4 | 展示第一名、第二名旗帜中 |
| CAN5 | 归位或停止流程中 |
| CAN6 | 电机控制故障锁存，需撤权后重新建立参考 |

| 右上ERR | 含义 |
| --- | --- |
| 0 | 无记录错误 |
| 1 | 应用应答超时 |
| 2 | 驱动返回拒绝应答 |
| 3 | CAN报文故障或发送超时 |
| 4 | 驱动失能、堵转/保护，或驱动重启导致参考标志丢失 |
| 5 | 清零后编码器位置不在初始容差内 |
| 6 | 10秒操作时限内未确认双轴到位 |

大字 **MOTION ERROR2** 与右上 **CAN…ERR2** 属于不同功能，记录问题时同时拍到两处状态。收到命令ACK不等于电机已经到位；以控制器完成状态/位置核对后的状态为准。

## 10. 故障恢复与撤销授权

1. 出现CAN6或ERR非0时，先不要继续按K2。
2. 将**SW2拨回0**，撤销授权；控制器按当前状态执行停止/失能流程并作废参考。
3. 检查电源、共地、总线两端终端、电机ID/波特率及机构是否卡住。
4. 用户通过驱动自身方式确认可安全手动归位，再将两轴放回机械初始位置；SW3先拨到0。
5. SW2重新拨到1，等CAN1稳定，再将SW3从0拨到1，等待CAN3/ERR0。
6. 清空赛道，按正常比赛步骤重新准备。

**SW2撤权不是独立硬件急停。** 总线断线或驱动异常时，不能保证停止命令已经到达；实际紧急情况使用驱动/供电系统的硬件措施。切换到ORIG、退出回放或按K1，不会替代撤销电机授权。

## 11. 最短操作口诀

**上电SW2/SW3关 → 两轴人工初始位 → SW2开 → 等CAN1 → SW3关到开 → 等CAN3/ERR0 → 短K2 → 等运动绿色READY → 放车 → DONE/自动展示 → 长K2回放 → 短K2退出回放 → 再短K2开始下一局。**

常见混淆：

- READY后直接放车，别再按K2。
- COLOR退出编辑：长K2；FILL退出编辑：长K1。
- 回放时K3/K4翻页；非回放MOTION空闲/结果时K3/K4调运动参数。
- 下一局用短K2自动收旗；不要用SW3在伸出位置重新清零。
- 颜色参数本次运行有效，复位或掉电即恢复默认。
